# Plan: 개발자 보스 테스트 모드

결정 문서: [개발자 보스 테스트 모드](../decisions/2026-11-16-caravan-dev-boss-test-mode.md)

## Goal
개발자 메인 화면의 게임 로고를 눌러 보스 선택 패널을 열고, 원하는 보스를 실제 캠페인 출현 시점에서 즉시 테스트한다. 테스트 런은 계정 저장·랭킹·보상과 완전히 분리한다.

## 확정 동작
- 개발 모드(`import.meta.env.DEV`)에서 메인 배너 로고를 클릭하면 오른쪽 보스 선택 패널을 토글한다. 프로덕션에서는 로고가 일반 이미지로만 동작하고 개발 패널/실행 기능이 없다.
- 선택 목록은 용암 거인·라바 매지션(300초), 성채 장군(600초), 숲의 수호자(900초), 빙의된 공주·왕과 근위병(1200초)이다. 선택한 보스를 카르마와 무관하게 강제로 소환한다.
- 테스트 전용 원정 ID와 월드 설정을 사용하며 `RunController.startNew`, snapshot 저장, 결과 제출·재시도를 호출하지 않는다. 일반 진행도와 랭킹은 변경되지 않는다.
- 테스트 캐릭터는 전사다. 테스트를 종료하거나 일시정지 메뉴에서 야영지로 돌아갈 수 있다.

## 완료 기준
- 개발 빌드에서만 로고 클릭으로 보스 패널이 열리고, 각 선택이 지정 시점과 보스 ID에 대응한다.
- 테스트 런 결과·체크포인트·일시 저장 요청이 서버 컨트롤러에 전달되지 않으며 야영지 복귀가 가능하다.
- 운영 빌드는 테스트 패널과 강제 소환 기능을 노출하지 않는다.
- 지정된 테스트와 웹 빌드가 통과한다.
