# Plan: 2026-11-16-caravan-boss-post-clear-tests

## 목표
개발자 보스 테스트 패널에서 각 중간보스를 처치한 직후의 캠페인 시각과 다음 맵 전환 상태로 시작할 수 있게 한다.

## Phase
- P01: 보스 클리어 후 테스트 시나리오 및 실행 흐름

## 범위
- 기존 보스 출현 테스트를 유지한다.
- 5분 라바 보스 선택지는 어두운 폐허 전환 시작으로, 10분 성채 장군은 숲 전환 시작으로, 15분 숲 수호자는 초원·마을 전환 시작으로 연결한다.
- 최종 보스 클리어 후 맵은 원정 종료 상태이므로 별도 항목으로 추가하지 않는다.
- 로컬 개발 테스트는 서버 저장 및 기록 제출에서 제외한다.

## 완료 조건
- 개발자 패널에서 기존 보스 조우 테스트와 중간보스 클리어 후 테스트를 각각 시작할 수 있다.
- 클리어 후 테스트에서 해당 보스 마일스톤이 완료된 것으로 처리되고, 시작 시점부터 다음 바이옴 전환이 진행된다.
- 일반 플레이와 기존 보스 조우 테스트 동작을 유지한다.
- 관련 단위 테스트, 웹 타입 검사, 프로덕션 빌드가 통과한다.
