# Decisions: 마차와 겹치는 마법진 레이어

- Date: 2026-11-16
- Status: Confirmed

## D01. 마법진의 마차 앞뒤 배치
- **Chosen**: 마법진의 100 월드픽셀 시각 범위가 마차 그림 영역과 겹치면 마법진 전체를 마차 뒤 깊이로 보낸다. 겹치지 않으면 현재 깊이로 유지한다.
- **Rationale**: 마차 위에 마법진이 그려지는 것을 막으면서, 마차에서 떨어진 마법진의 가시성은 유지한다.
- **Implementation assumption**: 마차 그림은 중심 기준 248×142px, 마차 깊이는 6이다. 겹치는 마법진은 깊이 5, 나머지는 기존 깊이 7로 둔다.
