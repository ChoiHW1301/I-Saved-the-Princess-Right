# Decisions: 용암 마법진 범위와 매지션 위치

- Date: 2026-11-16
- Status: Confirmed

## D01. 마법진 표시 범위
- **Chosen**: 마법진 그래픽의 지름과 플레이어가 공격할 수 있는 타격 반경을 폭발 판정 반경 100 월드픽셀에 맞춘다. 원형 범위 링은 마법진 소환 이후 계속 보이고 마지막 0.3초에는 기존 경고 채움 효과를 겹친다.
- **Rationale**: 마법진을 볼 때 실제 위험 범위와 공격 가능한 범위를 일관되게 파악할 수 있다.

## D02. 마법진 파괴 연출
- **Chosen**: 플레이어 공격으로 마법진이 파괴되면 중심에서 금빛·주황색 픽셀 파편이 흩어지고, 동일한 반경 100의 짧은 원형 충격파가 재생된다. 시간 만료 폭발은 기존 폭발 연출과 피해 흐름을 유지한다.
- **Rationale**: 공격으로 제거된 결과를 즉시 알아볼 수 있게 하면서 폭발과 구분한다.

## D03. 라바 매지션의 가장자리 위치
- **Chosen**: 매지션 시작과 체력 10% 구간 순간이동은 화면 왼쪽 중앙, 오른쪽 중앙, 위쪽 중앙, 아래쪽 중앙 네 위치 중 하나로 고른다. 스프라이트가 화면 경계 밖으로 나가지 않도록 보스 반경만큼 안쪽에 둔다.
- **Rationale**: 화면의 네 변 중앙에 배치해 고정형 보스 위치를 명확히 보여주고, 이미 확정된 가장자리 순간이동 규칙을 유지한다.
