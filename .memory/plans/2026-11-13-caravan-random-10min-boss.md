# Plan: 무작위 용암 보스와 캠페인 슬롯

결정 원문: [10분 무작위 중간 보스](../decisions/2026-11-13-caravan-random-10min-boss.md)

## Goal
5분 중간 보스 슬롯에서 용암 거인 또는 라바 매지션을 동등 확률로 선택하고, 각 보스의 고유 기믹을 구현한다. 10분에는 성채 장군 더미 보스를 사용하며 15분 숲 수호자와 20분 카르마 최종 보스는 유지한다. 중간 보스전 동안 시간·맵 전환을 멈추고, 처치 뒤 전환을 이어간다. 활성 보스와 기믹 상태는 임시 저장/이어하기에서 복원한다.

## 확정된 게임 규칙
- 5분 슬롯에서 용암 거인과 라바 매지션을 각각 50% 확률로 선택한다. 5분 슬롯 ID는 `lava-5min-slot`, 새로운 런의 실제 보스 ID는 `lava-giant` 또는 `lava-magician`으로 저장한다. 10분 성채 장군 슬롯 ID는 `castle-warlord-10min`, 실제 보스 ID는 기존 `castle-warlord`다.
- 전체 캠페인 보스 일정은 5분 무작위 용암 보스, 10분 성채 장군 더미, 15분 숲 수호자, 20분 카르마별 최종 보스다.
- 용암 거인의 돌진 예고는 2초, 예고 시작 간격은 6초다. 예고 중 반투명 방향 화살표가 플레이어를 따라가며, 돌진 시작 순간 방향이 고정된다. 돌진 속도는 초당 360 월드픽셀이다. 돌진 피해는 플레이어와 마차 각각 40이고, 두 대상을 관통하며 화면 경계에서 멈춘다.
- 거인이 경계에 닿으면 넘어져 4초간 스턴에 걸리고, 이때 받는 피해가 1.5배다. 스턴 중에는 다음 돌진 예고를 시작하지 않는다.
- 용암 거인은 상·하·좌·우 4방향 그래픽을 쓰고 좌우 반전으로 재활용한다. 대각선 방향은 가까운 그래픽 방향을 쓴다.
- 라바 매지션은 화면 위쪽에서 등장한다. 최대 체력에서 10%씩 잃을 때마다 순간이동한다. 한 번의 피격이 여러 경계를 넘겨도 순간이동은 한 번만 발생한다. 순간이동 지점은 마차 충돌영역을 제외한 화면 가장자리 안쪽이다.
- 마법진은 처음 4초 뒤 소환하며, 최대 체력에서 잃은 체력 10%마다 다음 소환 간격이 0.1초씩 줄어든다. 소환 지점은 25% 확률로 마차 중심 반경 120 월드픽셀 안, 75% 확률로 맵 전체에서 뽑는다.
- 마법진은 충돌하지 않으며, 실제 개별 공격 타격 3회에 파괴된다. 다중 투사체는 각각 타격으로 센다. 파괴되지 않은 마법진은 생성 3초 뒤 폭발해 반경 100 월드픽셀 안의 플레이어와 마차에 각각 25 피해를 준다. 마법사 처치 후에도 이미 생성된 마법진은 남아 기존 시점에 폭발한다.
- 모든 중간 보스가 활성화된 동안 캠페인 시간과 맵 전환을 멈춘다. 해당 보스를 처치하면 시간이 재개되고, 처치 조건을 만족한 맵 전환이 진행된다.

## 코드베이스 기준
- 현재 일정은 5분 `castle-warlord`, 10분 `lava-behemoth`, 15분 `forest-warden`, 20분 카르마 최종 보스다. 변경 후에는 5분 무작위 용암 보스, 10분 `castle-warlord` 더미, 15분 숲 수호자, 20분 카르마 최종 보스다.
- 새 슬롯 ID는 `lava-5min-slot`과 `castle-warlord-10min`; 실제 보스 ID는 별도로 기록한다. 5분과 10분 슬롯에서 `castle-warlord` 실제 ID가 중복될 수 있으므로 save snapshot에는 완료 슬롯 ID도 기록한다.
- 기존 `lava-behemoth` 보스 기준값은 최대 체력 220, 접촉 피해 20, 이동 속도 42다. 구형 저장과 결과 기록 호환을 위해 카탈로그에 유지하고, 두 신규 선택 보스는 이 기준값을 기본 스탯으로 사용한다. 거인의 돌진 피해 40 및 마법진 피해 25는 별도 기믹 피해다.
- 현재 보스 복원 경로는 보스 이동 속도를 항상 48로 만들지만, 시작 경로는 중간 보스 42·최종 보스 48을 쓴다. 저장 후 전투 감각이 달라지지 않도록 이동 속도를 `BossDefinition`에서 시작·복원 모두 읽게 한다.
- 현재 무기 시스템은 `Enemy[]`만 공격 대상으로 받는다. 마법진 타격을 위해 명시적인 공격 대상 인터페이스를 추가하되, 화상은 `Enemy`에만 적용한다.
- 저장 스키마는 버전 1의 strict Zod 스키마다. 신규 저장 필드는 기본값을 두고 구형 저장에서 완료 슬롯 ID를 기존 elapsed time·boss ID로 마이그레이션한다.
