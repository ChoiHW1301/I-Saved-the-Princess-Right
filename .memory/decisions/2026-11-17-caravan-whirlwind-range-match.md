# Decisions: 훨윈드 검 궤적과 피해 범위 일치

- Date: 2026-11-17
- Status: Confirmed

## D01. 범위 계산
- 훨윈드 검 궤적의 바깥 반경은 실제 검 타격 반경과 동일하게 한다.
- 기본 검 사거리 125와 `sword-range` 보너스를 모두 반영한다. 이전 궤적의 118 상한과 20% 반영 방식은 제거한다.
- `WeaponSystem`과 `CaravanScene`이 같은 범위 계산 함수를 사용한다.

## D02. 원형 일치
- 실제 훨윈드 판정은 플레이어 중심 원형이므로 시각 궤적도 원형 반경을 사용한다.
- 기존 회전 속도, 색, 앞뒤 레이어, 피해량은 유지한다.

## 기존 결정과의 관계
- `2026-11-17-caravan-whirlwind-sword-trail.md` D03의 시각 크기 상한은 이번 사용자 요청으로 대체한다.
