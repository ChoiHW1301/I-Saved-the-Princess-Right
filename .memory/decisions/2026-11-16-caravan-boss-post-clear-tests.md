# 보스 클리어 후 장면 테스트

## 결정
- 개발자 보스 테스트 패널에 중간보스 클리어 직후부터 시작하는 별도 항목을 추가한다.
- 5분 라바 보스(용암 거인 또는 라바 매지션) 처치 후에는 어두운 폐허 전환의 시작 장면을 연다.
- 10분 성채 장군 처치 후에는 숲 전환의 시작 장면을 연다.
- 15분 숲 수호자 처치 후에는 초원·마을 전환의 시작 장면을 연다.
- 시작 시각과 클리어된 캠페인 마일스톤을 미리 설정하여, 다음 맵이 서서히 나타나는 실제 플레이 상태를 확인할 수 있게 한다.
- 개발자 테스트 실행은 기존 보스 테스트와 같이 계정 저장 및 원정 결과 제출을 하지 않는다.
- 최종 보스는 원정 종료 흐름이므로 이번 “중간보스 클리어 후 맵 전환” 테스트 항목에는 포함하지 않는다.

## UI
- 개발자 보스 패널에 기존 “보스 출현” 항목과 구분되는 “보스 클리어 후” 목록을 추가한다.
- 각 항목은 보스명과 다음 구간명을 표시한다.
