# Decisions: 라바 매지션 순간이동과 보스 이름 표시

- Date: 2026-11-16
- Status: Confirmed

## D01. 순간이동 연출
- **Chosen**: 라바 매지션은 현재 위치에서 짧게 축소·페이드아웃한 뒤 새 위치로 이동하고, 주황빛 파편/원형 효과와 함께 다시 페이드인한다.
- **Rationale**: 사라짐과 등장 시점을 분리해 순간이동을 알아보기 쉽게 하고, 용암 테마와 맞춘다.
- **Edge case**: 연출 도중 다시 체력 구간을 넘어 텔레포트가 발생하면 목적지를 하나 대기시켜 첫 연출 뒤 순서대로 재생한다.

## D02. 보스 이름 배너 위치
- **Chosen**: 보스 등장 이름 배너를 화면 중앙에서 화면 하단 중앙(아래쪽 여백 14px)으로 옮긴다.
- **Rationale**: 개발자 보스 테스트 중 전투 중앙 시야를 가리지 않게 한다.
