# Decisions: 라바 매지션 텔레포트 중복 방지와 저체력 압박

- Date: 2026-11-16
- Status: Confirmed

## D01. 순간이동 중복 위치 방지
- **Chosen**: 매지션은 현재 위치로 다시 텔레포트하지 않는다. 연출 중에는 현재 위치, 이동 예정 위치와 대기 중인 위치도 다음 목적지 후보에서 제외한다.
- **Rationale**: 텔레포트가 제자리 연출처럼 보이거나 연속 이동이 같은 좌표를 반복하는 일을 막는다.

## D02. 체력 절반 이하의 플레이어 표적 마법진
- **Chosen**: 체력이 최대치의 50% 이하가 되면 매 소환 주기마다 기존 랜덤 위치 마법진 하나와 플레이어 현재 위치 마법진 하나를 함께 생성한다.
- **Rationale**: 기존 패턴을 유지하면서 저체력 구간에 플레이어를 직접 압박한다.
