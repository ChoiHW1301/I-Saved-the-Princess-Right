# 공주님을 구했다!? — 현재 구현 현황

> 2026-11-17 `main` 코드 기준. 수치는 기본값이며 상점 강화, 레벨업 선택, 전투 시간에 따라 달라집니다. 이 문서는 기획안보다 **실제 코드 동작**을 우선해 정리했습니다. 아래에는 캐릭터 해금과 결말에 관한 스포일러가 포함됩니다.

## 게임 한눈에 보기

공주를 구한 뒤 마차를 호위해 왕국으로 돌아가는 20분짜리 싱글 플레이 게임입니다. 4:3 전장 안에서 마차는 화면 중앙의 길을 따라가는 연출로 움직이고, 플레이어는 WASD/방향키로 이동하며 마우스 방향으로 자동 공격합니다. 적이 근처에 없어도 공격은 계속 나갑니다. 레벨업 때 무작위 강화 후보 3개 중 하나를 고릅니다.

| --- | --- | --- |
| 시작 | 일반 전투 | 용암지대 |

중간·최종 보스전에는 원정 시계와 일반 몬스터 신규 생성이 멈춥니다. 중간 보스전의 기존 몬스터는 남고, 최종 보스전에는 제거됩니다. 배경 전환은 보스 처치 후 진행됩니다. 일반 몬스터는 처음 약 2초 뒤부터 나오고, 초기 생성 간격은 3초이며 시간이 흐르면 최대 1.2초 간격까지 짧아집니다. 동시 일반 적은 최대 36마리입니다.

## 이벤트·카르마·엔딩

카르마는 −100부터 +100까지이며 시작값은 0입니다. **악 ≤ −50**, **선 ≥ +50**, 그 사이는 **중립**입니다. 이벤트 선택 화면에서는 Yes/No를 고르고, 선택 결과는 카르마·마차 내구도·원정 중 골드에 반영됩니다.

| 시점 | 이벤트 | Yes: 카르마 / 마차 / 골드 | No: 카르마 / 마차 / 골드 |
| --- | --- | --- | --- |
| 3분 | 성채의 전령 | +12 / −12 / −2 | −8 / 0 / +2 |
| 6분 | 버려진 보급 마차 | −5 / +8 / +8 | +6 / 0 / 0 |
| 9분 | 포로가 된 정찰병 | +14 / −8 / 0 | −11 / 0 / +5 |
| 12분 | 마을의 피난민 | +16 / −18 / −3 | −13 / 0 / +6 |
| 18분 | 숲길의 약초꾼 | +10 / −10 / 0 | −5 / 0 / +5 |

선·중립은 빙의된 공주와 싸웁니다. 선으로 승리하면 공주가 정화되어 살아나고, 중립으로 승리하면 공주가 사망합니다. 악은 왕과 근위병을 상대하며 전사가 새로운 마왕이 되는 결말입니다.

**현재 구현상의 차이:** 다섯 이벤트의 가장 악한 선택을 모두 골라도 카르마는 **−42**입니다. 따라서 일반 플레이에서 악 기준 −50에 도달할 수 없어 악 보스·결말은 사실상 열리지 않습니다. 또한 설계상 이야기한 악 루트 클리어 후 흑화 전사 해금은 아직 구현되지 않았습니다.

## 저장·랭킹과 확인할 점

- 사내 Microsoft Entra ID 로그인 뒤 플레이할 수 있습니다. 프로필의 골드, 해금 캐릭터, 상점 강화·훈련과 원정 임시저장은 Azure의 게임 전용 `caravan-game` 데이터베이스에 저장됩니다.
- 점수는 `처치×100 + 생존 초 + 처치한 보스×500 + 클리어 시 2,000`입니다. 점수 랭킹은 상위 10위를 표시하며, 클리어 랭킹은 캐릭터·카르마별로 나뉩니다.
- **현재 서버가 지급하는 골드**는 `처치 수 + ⌊생존 초÷60⌋×5 + 클리어 시 50`입니다. 전투 중 보이는 `runGold`, 몬스터·이벤트·머니 밤에서 얻은 골드는 결과 제출 데이터에 포함되지 않아 현재 프로필 보유 골드에 더해지지 않습니다. 골드 획득량 영구 강화도 이 서버 계산에는 반영되지 않습니다.
- 황금 임프 경험치 드롭은 현재 코드에서 항상 구울 기본 경험치의 5배(15)입니다. 앞서 논의한 “처치 시점 일반 몬스터 경험치의 5배”와 차이가 있습니다.
