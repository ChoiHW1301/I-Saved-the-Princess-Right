# Decisions: 개발자 보스 테스트 모드

- Date: 2026-11-16
- Status: Confirmed

## D01. 숨겨진 진입과 보스 선택
- **Chosen**: 개발자 빌드 메인 화면에서 게임 로고를 클릭하면 개발자 모드가 활성화되고 화면 오른쪽에 보스 선택 패널이 열린다. 보스를 클릭하면 해당 보스가 원래 출현하는 캠페인 시점으로 즉시 이동해 선택한 보스를 확정 소환한다.
- **Rationale**: 일반 플레이 흐름에서 숨겨진 진입을 유지하면서 기믹이 있는 보스를 빠르게 반복 테스트할 수 있다.

## D02. 보스별 테스트 시점
- **Chosen**: 용암 거인과 라바 매지션은 5분(300초), 성채 장군은 10분(600초), 숲의 수호자는 15분(900초), 빙의된 공주와 왕과 근위병은 최종 보스 시점(1200초)에 소환한다. 카르마와 무관하게 선택한 최종 보스를 강제한다. 현재 캠페인에 없는 레거시 `lava-behemoth`는 선택 목록에서 제외한다.
- **Rationale**: 테스트 런의 바이옴·시간과 보스 등장 시점이 실제 일정과 맞고, 최종 보스 루트도 각각 확인할 수 있다.

## D03. 테스트 런 데이터 격리
- **Chosen**: 개발자 테스트 런은 기존 계정의 새 원정·저장 데이터를 만들거나 수정하지 않고, 랭킹 제출과 보상 기록도 건너뛴다. 테스트 런 종료와 일시정지 화면에서는 저장 대신 야영지로 돌아갈 수 있게 한다. 진입 패널과 동작은 Vite 개발 빌드에서만 활성화한다.
- **Rationale**: 보스 반복 테스트가 일반 계정 진행도와 랭킹을 오염시키지 않게 한다.

## D04. 시작 캐릭터
- **Chosen**: 보스 테스트는 해금이 보장된 전사로 시작한다.
- **Rationale**: 보스 선택과 캐릭터 해금 상태를 분리하고 언제나 테스트를 시작할 수 있게 한다.
