# Plan: 용암 중간 보스 조정

결정 문서: [용암 중간 보스 조정](../decisions/2026-11-16-caravan-lava-boss-tuning.md)

## Goal
용암 거인과 라바 매지션의 전투 존재감을 높이고, 매지션을 가장자리 고정형 보스로 정리한다. 용암 거인 돌진을 1080 월드픽셀/초로 높이고, 매지션은 가장자리 간 순간이동만 하게 하며 마법진을 한 타격에 부수고 소환 주기를 전체적으로 두 배 빠르게 한다.

## 확정 동작
- 용암 거인과 라바 매지션의 표시 가로·세로 크기를 기존 대비 2배로 하고, 해당 용암 보스 공격 판정 및 화면 여백도 커진 몸 크기에 맞춘다.
- 용암 거인 돌진은 360에서 1080 월드픽셀/초로 변경한다.
- 라바 매지션은 화면 상·하·좌·우 가장자리 중 한 곳에 생성되어 움직이지 않는다. 체력 10% 구간마다 충돌 불가인 마차 영역을 피해서 다른 가장자리로 순간이동한다.
- 마법진은 HP 1, 기본 소환 간격 2000ms, 체력 10% 손실당 간격 감소 50ms, 최소 간격 1500ms로 설정한다. 기존 저장 마법진의 HP도 생성 시 최대 HP 1로 정규화한다.

## 완료 기준
- 단위 테스트가 돌진 속도, 소환 주기 배율, 마법진 한 타격 파괴, 가장자리 위치/매지션 정지 흐름의 경계를 확인한다.
- 웹 타입 검사와 프로덕션 빌드가 통과한다.
